# Участие в разработке

Для работы нужны Node.js 24+ и pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Создавайте ветку от `main` с понятным названием, например `feat/strategy-editor`
или `fix/score-validation`. В pull request опишите проблему, результат и проверку.

Перед отправкой выполните:

```sh
pnpm test
pnpm typecheck
pnpm build
```

Тесты расчётов находятся рядом с кодом в `src/lib/*.test.ts`. При изменении
расчётов добавляйте проверку соответствующего поведения. Для изменений
интерфейса проверяйте основной сценарий вручную и прикладывайте скриншоты.

Официальные правила симуляции и необязательные прогнозы до 2050 года должны
оставаться разделены. Описание архитектуры и правил есть в [README](README.md),
дополнительные материалы — в [docs](docs/README.md).

Не добавляйте API-ключи, `.env`, архивы с локальными данными и результаты сборки.
Новые настройки окружения документируйте в `.env.example` без реальных значений.
