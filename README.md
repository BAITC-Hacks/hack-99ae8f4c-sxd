# FARSIGHT

Future Akim Strategy & Impact Governance Tool

FARSIGHT is an AI-powered urban strategy simulator for evaluating how Akim decisions affect Astana’s districts in the short term and how those choices may shape the city toward 2050.

The project is built around the HackAlem case “Akim for 5 Hours”. The core case requires a user to work with a fixed budget, choose exactly five urban initiatives across transport, ecology, social infrastructure, safety and city services, and receive an Astana Quality of Life Score with an explanation of the impact of those decisions.

FARSIGHT keeps that logic as the foundation. The user describes a strategy in natural language, for example “Industrial-Mobility First” or “Green Growth”. The AI interprets the intent and converts it into a valid set of five initiatives. The system checks the budget, incompatibilities and other constraints, then runs the deterministic simulation model and calculates the resulting Quality of Life Score.

The numerical score is not generated by the LLM. The simulation engine applies the provided effects, implementation lags, synergies, district weights and scoring formula. The LLM works above that layer: it understands the strategy, compares scenarios, explains trade-offs and suggests changes.

On top of the original two-year simulation, FARSIGHT adds a long-term scenario layer aligned with the Kazakhstan 2050 planning horizon. The goal is not to predict the future as a single fixed outcome, but to show how different strategic directions could evolve over time under explicit assumptions.

A user can compare strategies such as Industrial-Mobility and Green Growth and see how their trajectories differ across transport, ecology, social infrastructure, safety, city services and the overall Astana Quality of Life Score.

The main flow is:

```text
User Strategy
→ AI Strategy Agent
→ Validator
→ Simulation Engine
→ 2050 Scenario Layer
→ Strategy Comparison
→ AI Explanation
```

The application is built with Next.js, TypeScript, Tailwind CSS, shadcn/ui and Recharts. The simulation and validation logic run deterministically in TypeScript, while NVIDIA / LLM APIs are used for strategy interpretation, comparison and explanation.

Run locally:

```bash
npm install
npm run dev
```
